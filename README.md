# Indian-Financial-Market-Analysis-
Project Name: Indian Financial Market Analysis  This Dashboard helps us to understand the structure of the Indian Financial Market by analysing Stocks, Commodities, and Investment Funds, and to help beginner investors evaluate market performance, risk, returns, and diversification opportunities through interactive Power BI dashboards.

Tools Used

- Microsoft Power BI
- Power Query (if used)
- DAX (if used)

Problem Statement

If an investor has money to invest, where should they invest among Stocks, Commodities, and Investment Funds?

This helps investors identify suitable investment opportunities from 2023–2025 by comparing the performance, risk, and returns of the financial instruments in the Market .

Dashboard Preview

The dashboard screenshot is available in this repository as "dashboard.png".

Key Features

- Market performance KPIs
- 3 Year Growth of all the Shares,Commodities and fund
- Comparison between Commodities and Funds 
- Interactive filters and charts

Key Insights

Market showed long-term upward movement.
Gold delivered stable returns and acted as a safe-haven asset.
Silver showed balanced performance due to precious and industrial demand.
Copper carried the highest risk because it depends on industrial growth.
Commodity returns varied across economic cycles.
Diversification across commodities can reduce portfolio risk.
